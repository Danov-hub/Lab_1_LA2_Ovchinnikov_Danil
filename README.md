## Задача 7

### Текст задачи

Диапазон.

Дана сигнатура метода: public bool isInRange(int a, int b, int num);

Метод принимает левую и правую границу (a и b) некоторого числового
диапазона. Необходимо реализовать метод таким образом, чтобы он возвращал
true, если num входит в указанный диапазон (включая границы). Обратите
внимание, что отношение a и b заранее неизвестно (неясно, кто из них больше,
а кто меньше).

1. Принимаем три числа: a, b, num.
2. Сравниваем a и b:
   - если a < b, то min = a, max = b;
   - иначе min = b, max = a.
3. Проверяем, что num больше или равен min и меньше или равен max.
4. Возвращаем результат проверки.

4. Если истинно хотя бы одно из них (del3 ИЛИ del5) - возвращаем true.
5. Иначе возвращаем false.

## Задача 3

### Текст задачи

Поиск максимального.

Дана сигнатура метода: public int maxAbs(int[] arr);

Необходимо реализовать метод таким образом, чтобы он возвращал наибольшее
по модулю (то есть без учёта знака) значение массива arr.

Пример:
arr = [1, -2, -7, 4, 2, 2, 5]

результат: -7

### Алгоритм решения

1. Принимаем массив arr.
2. За начальный максимум берём arr[0].
3. Пробегаем по массиву, начиная с индекса 1.
4. Если модуль текущего элемента больше модуля текущего максимума -
   обновляем максимум (запоминаем сам элемент, не модуль).
5. Возвращаем найденный элемент.

## Задача 5

### Текст задачи

Добавление массива в массив.

Дана сигнатура метода: public int[] add(int[] arr, int[] ins, int pos);

Необходимо реализовать метод таким образом, чтобы он возвращал новый
массив, который будет содержать все элементы массива arr, однако в позицию
pos будут вставлены значения массива ins.

Пример:
arr = [1, 2, 3, 4, 5]
ins = [7, 8, 9]
pos = 3

результат: [1, 2, 3, 7, 8, 9, 4, 5]

### Алгоритм решения

1. Принимаем массивы arr, ins и позицию pos.
2. Создаём новый массив result длиной arr.Length + ins.Length.
3. Копируем элементы arr от 0 до pos - 1 в начало result.
4. Копируем элементы ins начиная с позиции pos.
5. Копируем оставшиеся элементы arr (от pos до конца) сразу после
   вставленных элементов ins.
6. Возвращаем result.

## Задача 7

### Текст задачи

Возвратный реверс.

Дана сигнатура метода: public int[] reverseBack(int[] arr);

Необходимо реализовать метод таким образом, чтобы он возвращал новый
массив, в котором значения массива arr записаны задом наперёд.

Пример:
arr = [1, 2, 3, 4, 5]

результат: [5, 4, 3, 2, 1]

### Алгоритм решения

1. Принимаем массив arr.
2. Создаём новый массив result той же длины.
3. В цикле по i от 0 до arr.Length - 1:
   result[i] = arr[arr.Length - 1 - i].
4. Возвращаем result.

## Задача 9

### Текст задачи

Все вхождения.

Дана сигнатура метода: public int[] findAll(int[] arr, int x);

Необходимо реализовать метод таким образом, чтобы он возвращал новый
массив, в котором записаны индексы всех вхождений числа x в массив arr.

Пример:
arr = [1, 2, 3, 8, 2, 2, 9]
x = 2

результат: [1, 4, 5]

### Алгоритм решения

1. Принимаем массив arr и число x.
2. Первым проходом по массиву считаем, сколько раз встречается x
   (переменная count).
3. Создаём новый массив result длиной count.
4. Вторым проходом по массиву записываем индексы всех вхождений x в result.
5. Возвращаем result.
